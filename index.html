Step 1 — Test connection

The token stays in this browser's storage and is only ever sent to your ChemInventory instance. Use a token from an account with normal user permissions.

If the test fails

An error like Failed to fetch almost always means ChemInventory is blocking requests coming directly from the browser (CORS). The only fix then is a small relay service running on a machine at the institute — or sticking with the scan-to-move tool on the ChemInventory site itself. An error with text from ChemInventory, on the other hand, means the connection works and only the token is wrong.
