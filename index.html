Schritt 1 — Verbindung prüfen

Der Token bleibt im Speicher dieses Browsers und wird an niemanden außer deine ChemInventory-Instanz gesendet. Nimm einen Token auf ein Konto mit normalen Nutzerrechten.

Wenn der Test fehlschlägt

Ein Fehler wie Failed to fetch bedeutet fast immer, dass ChemInventory Anfragen direkt aus dem Browser blockt (CORS). Dann hilft nur ein kleiner Vermittler-Dienst auf einem Rechner im Institut — oder du bleibst beim Scan-to-Move-Tool auf der ChemInventory-Seite. Ein Fehler mit Text aus ChemInventory heißt dagegen: Verbindung steht, nur der Token stimmt nicht.
